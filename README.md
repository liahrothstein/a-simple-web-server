# 🌐 A Simple Web Server

REST API сервер на базе **Node.js** и **Express**, реализующий систему управления пользователями и книжным каталогом. В проекте применена многослойная архитектура (**Controller-Service-Repository**) для обеспечения чистоты кода и легкости масштабирования.

## 🚀 Основные возможности

* **Полная аутентификация**: Регистрация, логин, логаут и обновление токенов доступа.
* **Безопасность**:
    * Хеширование паролей с использованием `bcryptjs`.
    * Безопасное хранение токенов в `httpOnly` cookies.
    * Защита приватных роутов через JWT-авторизацию.
* **Валидация**: Проверка входящих данных на уровне роутов с помощью `express-validator`.
* **Слой доступа к данным**: Использование репозиториев для изоляции логики работы с **MongoDB/Mongoose**.
* **Обработка ошибок**: Централизованный Middleware для обработки исключений и кастомный класс `ApiError`.

## 🛠 Технологический стек

* **Runtime**: Node.js (ES Modules)
* **Framework**: Express
* **Database**: MongoDB & Mongoose
* **Auth**: JSON Web Token (JWT) & BcryptJS
* **Utilities**: Cookie-parser, CORS, Dotenv, UUID

## 📂 Архитектура проекта


* `controllers/` — прием запросов и отправка ответов.
* `services/` — основная бизнес-логика.
* `repositories/` — прямые запросы к базе данных.
* `models/` — схемы данных (User, Token, Book).
* `dtos/` — объекты трансформации данных (Data Transfer Objects).
* `middlewares/` — проверка авторизации и обработка ошибок.
* `validation/` — логика валидации полей (например, при регистрации).

## 📡 API Эндпоинты

### Пользователи (`/api`)
| Метод | Эндпоинт | Описание | Доступ |
|:---|:---|:---|:---|
| POST | `/registration` | Регистрация нового аккаунта | Публичный |
| POST | `/login` | Вход в систему | Публичный |
| POST | `/logout` | Выход (удаление cookie) | Публичный |
| GET | `/refresh` | Обновление Access Token | Публичный |
| GET | `/users` | Список всех пользователей | Только Auth |
| GET | `/user/:id` | Получение профиля по ID | Только Auth |
| PUT | `/update-user` | Редактирование профиля | Только Auth |
| DELETE | `/delete-user/:id` | Удаление аккаунта | Только Auth |

### Книги (`/api`)
| Метод | Эндпоинт | Описание | Доступ |
|:---|:---|:---|:---|
| GET | `/books` | Получить все книги | Только Auth |
| GET | `/book/:id` | Получить книгу по ID | Только Auth |
| POST | `/add-book` | Добавить новую книгу | Только Auth |
| PUT | `/update-book` | Редактировать данные книги | Только Auth |
| DELETE | `/delete-book/:id` | Удалить книгу | Только Auth |

## ⚙️ Установка и запуск

1.  **Клонируйте репозиторий**:
    ```bash
    git clone https://github.com/liahrothstein/a-simple-web-server.git
    cd a-simple-web-server
    ```

2.  **Установите зависимости**:
    ```bash
    npm install
    ```

3.  **Настройте окружение**:
    Создайте файл `.env` в корне и заполните его:
    ```env
    PORT=5000
    DB_URL=ваша_ссылка_на_mongodb
    JWT_ACCESS_SECRET=секретное_слово_1
    JWT_REFRESH_SECRET=секретное_слово_2
    ```

4.  **Запуск**:
    * Разработка (nodemon): `npm run dev`
    * Продакшн: `npm start`
